# 第三批：双因素、双栏、四栏、政策时间线与共同作用

版本：0.3.0。依据本轮7张用户参考图及原始PPT独立入库，累计16类基础组件、10个可选变体。本文图1至图7只指本批参考；原图保存为`reference-10.png`至`reference-16.png`，像素未改写。

## 组件与主要关系

| 图 | 组件ID | 关系与功能 |
| --- | --- | --- |
| 1 | BW-DUAL-FACTOR-01 | 两组因素影响中间结果，右侧图片解释机制或提供相关证据 |
| 2 | BW-TWO-CLASS-01 | 共同定义下的双类别、形成方式与来源，底部图组辅助解释 |
| 3 | BW-TWO-HIERARCHY-01 | 两个同层大主题，每栏再分子主题与条目 |
| 4 | BW-TWO-PERSPECTIVE-01 | 顶部总述统领两个并列图文视角 |
| 5 | BW-FOUR-PARALLEL-01 | 四栏共享字段和层级，可按内容使用文字或图片 |
| 6 | BW-POLICY-TIMELINE-01 | 时间节点、文件依据、实施层级、并行任务及策略转变 |
| 7 | BW-BILATERAL-CENTER-01 | 左右两侧共同作用于中间，底部图组或总结补充主线 |

## 图1：双因素作用与右侧图证

左边上、下两组是因素组，各自条目是子条件，中间是共同影响的结果或状态。自然/人为、四项/三项条件和寒潮/干旱属于原例，不能当作固定学科和固定作用方向。小结果节点适合短词，中心标签以两字为宜。

正向、负向、混合作用均可使用；红色只突出重点，不自动表示负面。提供“正向作用占位”变体，保留因素到结果的连接，把条件改为明确占位，并移除原负面案例的图证，等待绑定支持本次作用方向的真实图。

右栏两层图像分别服务机制解释和补充证据。原素材右侧图解不完整，且有字词异常，已作为来源缺陷记录，不直接继承为新文稿事实。

## 图2：双类别定义与来源

顶部蓝底黄字给共同定义，渐变引导两个胶囊类别名。各栏为定义句、竖向维度标签、来源条目和红色重点。两类是并列关系，不自动增加时间或因果箭头。

下方分类、尺度和场景图组按职责对应上文；其中一个视觉组由两个原生图片对象组成，不能仅按图片对象数量推导类别数，也不能只按左右位置猜测证据归属。

## 图3：双栏编号与分组条目

两栏是同层主题，各自包含两个子主题。编号与总标题、蓝色子标题、黑色正文及红色重点构成层级，可以说明正面作用、负面影响或一般特性。01/02只标识主题，不表示先后。

仅提取完整双栏结构，排除截图下缘不完整的其他图片。统一字体后曾出现编号换行，本版保持原字号和框体，通过清除文本框/段落多余内缩及单行居中修复。

## 图4：总述与双栏图文要点

顶部约两行总述覆盖左右两个视角。每栏为竖向视角名、主图、侧边短图解和下方要点，图负责解释或证据，文字负责主线。核心总结/未来展望可换成其他同层视角，不暗示左栏导致右栏。替换时图、图解和要点必须属于本栏同一主线。

## 图5：四栏并行与逻辑层级

四个等宽卡片共享标签、主题、特征和响应的顺序。原例用日期展示四阶段，但日期是可替换标签，不是本组件固定的时间逻辑。可改为四类对象、方向或方案。

保留来源的字号层级：主标题18pt、正文13pt、维度标签12pt、紧凑补充细节10pt。不能宣称所有正文都是16pt，也不能因替换内容过长继续缩字。局部证据区可放相关辅助图或细节文字；需要精读的复杂主图不宜放入狭小区域。

提供“四栏均采用文字细节”和“并行类别标签”两个变体。四栏还可分别选择图片或文字，真实图片等比放入对应局部证据区，不改变本栏主题与响应层级。

## 图6：时间线与政策治理

顶部是主判断，四节点时间线记录日期、事件和短解释；左下文件图及名称提供依据；中部先表达统筹、协调、落实层级，再以虚线框归纳八项并行任务；右侧概括策略转变。

时间顺序、组织层级、任务集合是三种不同关系。不能把八项任务硬连成流程，或把实施角色当成时间阶段。替换时核对日期顺序、文件名称、版本和发布主体。示例年份、政策表述及“至今”属于原材料，没有作为本次现行政策检索结论。

## 图7：两侧共同指向中心

```text
左侧内容  →  中间核心内容  ←  右侧内容
```

两支箭头均指向中间。左右可为条件、问题、机制、支持或约束，中间为共同定位的研究内容、问题或目标。已展开/拟展开是可替换名称；没有证据时不能把共同相关性表述为已证实的协同因果。

上方总述统领整个结构，下方可用相关图组，也可用综合解释或总结。提供“底部使用总结文字”变体；换下方内容时保留上方总述、左右内容、中央内容及两支相向箭头。底部图片数不等于研究类别数。

## 预览与导出

[离线组件目录](../library/index.html) 可预览、对照原图、定位功能分区并下载当前形式，槽位和下载文件随变体同步变化。

```powershell
python scripts/build_library.py --component BW-DUAL-FACTOR-01 --variant positive-placeholder --output positive-factors.pptx
python scripts/build_library.py --component BW-BILATERAL-CENTER-01 --variant bottom-text --output shared-effect.pptx
```

四栏逐栏选择的JSON示例，图片路径相对该JSON文件：

```json
{"kind":"four-content","modes":["image-text","text","text","text"],"images":{"1":"assets/本次相关图片.png"}}
```

```powershell
python scripts/build_library.py --component BW-FOUR-PARALLEL-01 --recipe-file four-choice.json --output four-columns.pptx
```

只接受本组件已授权的形式，导出同时保存`.selection.json`。接口执行选择和资产绑定，不调用外部模型；模型在真正制作时依据本次内容补充选择与理由。Word解析及整稿制作尚未实现。

### BW-DUAL-FACTOR-01：双因素作用与右侧图证

来源：联合基金(亚热带岩性森林 蓝色）.pptx，第7页对应区域。

| 区域 | 功能 | 替换内容 |
| --- | --- | --- |
| 顶部总述 | 限定作用对象、情境和主判断 | 一句能够覆盖两组因素及结果的总述 |
| 第一组因素 | 命名第一因素组，并以四个条件展开 | 组名与四个短条件；可表达促进或抑制 |
| 第二组因素 | 以另一因素组及三个条件补足解释 | 组名与三个短条件 |

| 因素与结果的连接 | 区分因素内部展开与两组指向中间结果的关系 | 保持方向；新内容必须有关系依据 |
| 右上机制或证据图 | 用图与局部标注解释作用机制或相关证据 | 一组相关图、标注及完整图解 |

### BW-BILATERAL-CENTER-01：左右共同作用于中心

来源：4白蓝色系-国家自然科学项目申请答辩结题汇报PPT.pptx，第11页对应区域。

| 区域 | 功能 | 替换内容 |
| --- | --- | --- |
| 上方总述 | 给出三栏共同回答的总问题或总目标 | 覆盖左右与中心的一句总述 |
| 左侧作用或支撑 | 以三条内容从左侧定位、支撑或约束中心 | 栏名及三条短内容 |
