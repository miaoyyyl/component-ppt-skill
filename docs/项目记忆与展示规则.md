# 项目记忆与展示规则

依据用户2026-11-02对镉污染修复成品的明确反馈，后续本项目PPT制作沿用以下约定，除非用户另行指定。

- 内容页正文、图题、图内和页脚不显示`[1]`、`[1–2]`等文献引用标记；完整出处、对应关系与链接保留在演讲备注、来源清单和文末参考文献中，不删除证据记录
- 不额外加入灰色小字的适用范围、口径、核验或制作补充，例如“操作性分级，不等于独立纯物相”“不同端点分别测量，不能互相替代”“移出污染介质，需处置闭环”；有用补充放入讲述备注，影响结论的单位、关键实验条件或不确定性用正常字号并入相应论述
- 页标题使用陈述式，如“控制镉迁移的因素”，不使用“哪些因素控制镉迁移”等疑问句
- 展示中的标题、段落、条目、图题及结论末尾不加句号等句读，保留句中标点、小数点、缩写和必要科学符号；不是全文删除所有标点，也不清理备注中的正常行文
- Word原图逐张判断并登记采用、裁切、重绘或不采用的理由；写实偏好针对视觉呈现，不自动否定科学流程/机制图，不因可生成新图就忽略用户原图
- 原图存在错误时先修正论述或重绘，存在未核准数据时不得把数字当成实测证据；可恢复地选择独立照片区域时保留原图字节、裁切坐标与出处，不据此宣称已核实拍摄地点
- 检查须覆盖原生文字和图片内文字；可使用`scripts/presentation_copy.py`检查最终PPT，再查看PowerPoint实际渲染；不以清单通过代替视觉复核
