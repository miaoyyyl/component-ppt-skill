# 统一内容页底板与检查记录

日期：2026-11-02。组件库版本0.4.0，主题版本0.2.0。

## 本次统一范围

按用户提供的第6张示例图，将15类内容页及10个变体，共25种形式统一为：

- 顶部独立页面标题，微软雅黑32pt、深蓝加粗，作为可替换的`pageTitle`槽位。
- 标题下方双层蓝色隔断，浅蓝衬线与深蓝主线沿用原生形状。
- 整页显式写入纯白背景，清理原设计中会叠加的母版图形、旧页头和页码，避免拼装后继承灰底或装饰背景。
- 内容区保持原有并列、总分、递进和共同作用关系，保留红黄强调。
- 底部统一深蓝条，无页码；内容中的01/02等层级编号继续保留。

章节切换目录沿用原导航版式，等距与激活规则不变。原始PPT、Word和原始组件参考图保持；新页框参考图另存[用户页框参考](../library/references/page-frame-reference.png)。本次修改组件库资产，没有修改某个主题的成稿内容。

## 原生页框参数

画幅1280×720。页标题框为`[36, 10, 1208, 64]`；隔断位于`y≈76.69–88.84`，底条位于`y≈713.23–720`。页标题、隔断、底条对象ID分别为`61000`、`61001`、`61002`，均为可编辑原生对象。

隔断和底条取自用户原始“1深蓝色系”PPT第6页的版式图形，再将颜色写为明确的`#0046A5`，避免颜色随目标主题改变。背景为幻灯片本身的`#FFFFFF`，不是以白色截图覆盖原背景。

9类缺少页标题的内容页补齐了标题槽位；已有页标题的版式也统一到同一页头范围。页框构建规则位于`scripts/page_frame.py`，主题参数在`library/theme.json`，各组件的位移及装饰留白调整在`library/components.json`的`pageFrame`中登记。

## JSON交接与旧任务

组件ID与变体ID保持。0.3任务读取时沿用人工选择、顺序、变体、备注和材料引用，使用当前0.4版母版；再次导出时更新文件路径、哈希、标题槽位、容量和页框约定。需要让后续Agent使用新页框时，读取旧任务后重新导出JSON。

组件库仍只负责选型、填写要求及JSON导出，不恢复库内Word上传或自动制作入口。Agent接手后按0.4母版逐框替换，并针对本次真实内容执行实际渲染检查。
