# X 占位母版与内容替换

日期：2026-11-02。覆盖16类组件及10个变体，共26种形式。

当前为0.4母版：25种内容页形式均已统一纯白画布、顶部页标题与蓝色隔断、底部深蓝条，无页码；目录沿用导航版式。X占位基于统一后的母版重新生成，字号、内容编号和图片尺寸继续保持。原字数指本版母版中的文字量；新增页标题同样提供容量参考。

组件库默认展示和下载X占位母版，可切换查看原案例版式。已公开的用户原始参考图可在同一位置查看。占位副本位于 `library/placeholders/`。

## 保留什么

- 按原文字逐字替换：中文使用全角`Ｘ`，英文和正文数字使用半角`X`；保留标点、空白、段落和结构编号。
- 每个文字框保留原字号、字体、粗细、红黄强调层级、对齐及框体位置尺寸。
- 图片保留原文件和图框大小、位置，供观察图文比例。图片内部文字属于图片像素，不改成X。
- 编号、箭头及框架关系保持。已在组件规范中授权可选的连接线，实际制作可按内容关系显示或隐藏。

全角X用于接近中文字宽；逐字占位保证原字符数量，不能保证替换为任意文字后仍完全相同的换行。标点和英文宽度也会影响行数，因此成稿必须重新渲染。

## 制作时怎样替换

模型先得到每个槽位的容量数据，再按逐页方案逐框组织本次内容。原字数作为体量参考，尽量保留相近文字量；不为凑字数编造内容，也不删掉必要条件、单位或限制。标题与正文仍使用对应框原有的字号层级，长内容先精简表达或放入备注。

图片逐框替换为本次Word原图或已登记来源的真实资产；保持图框，整图按比例适配，不拉伸、不裁掉图例和单位。占位母版中的案例图片不作为新主题证据。无法取得可靠图片时记录缺图，成稿标记待复核。

## 核验与重建

26种占位形式均经本机PowerPoint实际打开、渲染、保存副本和重开。程序逐一核对字数、原富文本样式、段落、几何尺寸及图片字节；记录见[占位检查](placeholder-check.json)与[实际渲染记录](placeholder-render.json)。这些检查针对母版，不代表所有后续文字都能直接装入。

在项目根目录运行：

```powershell
python scripts/build_placeholders.py --render
python scripts/check_placeholders.py
python scripts/build_library.py --viewer-only
```

修改原始组件后，应重新生成占位副本、实际渲染并更新浏览页数据，避免使用与组件版本不一致的占位图。
